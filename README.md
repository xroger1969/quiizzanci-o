# Quiz sfg-TPO (100 perguntas)

Quiz de treino para anciãos, baseado no **Pastoreiem o Rebanho de Deus (sfg‑TPO)** — pt‑PT.
- 4 opções por pergunta (estilo americano), 1 correta.
- Modo **Estudo** (feedback imediato) e **Exame** (corrige no fim).
- 100% estático (um único `index.html`), funciona offline.

## Como usar
1. Abre `index.html` diretamente no navegador **ou** publica com GitHub Pages.
2. Escolhe o modo (Estudo/Exame) e a ordem (Sequencial/Baralhar).
3. Usa o mapa para saltar para qualquer pergunta.

## GitHub Pages (rápido)
- Cria um repositório (ex.: `quiz-sfg-tpo`).
- Carrega estes ficheiros para a raiz.
- Em **Settings → Pages**, escolhe **Deploy from a branch**, branch **main**, pasta **/**.
- A página ficará disponível em: `https://<o-teu-utilizador>.github.io/quiz-sfg-tpo/`.

## Base de conteúdo
Perguntas preparadas a partir do sfg‑TPO (edição setembro 2025).
As referências em cada item indicam **Capítulo** e **§ parágrafo** para revisão.
